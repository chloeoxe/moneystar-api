# MoneyStar API
### Powered by: FastAPI & Supabase
This is the API for MoneyStar, a portfolio management application to track your investments effortlessly!

## Getting Started
1. Clone this repository
2. At the root of the repository, create a Python virtual environment:
```
python -m venv venv
```
3. Activate the Python virtual environment
4. Install the required packages:
```
pip install requirements.txt
```
5. Create a .env file as follows:
```
PROJECT_URL="<insert your supabase project URL>"
API_KEY="<insert your supabase API key>"
```
6. Start the API:
```
fastapi dev main.py
```
7. Head to http://127.0.0.1:8000 and a message should be displayed if the API works!
